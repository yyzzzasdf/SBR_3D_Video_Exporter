# 视频导出参数

参数优先级为内置默认值、JSON 配置文件、命令行覆盖。命令行参数使用短横线，例如 `--frames-x`；JSON 字段使用下划线，例如 `frames_x`。所有输入路径和显式指定的配置、输出路径相对于执行命令的当前目录；脚本默认路径相对于工具目录。

## 数据与运行

| 命令行参数 | 作用 |
|---|---|
| `--data` | 输入目录；默认使用随包合成数据 |
| `--cube` | 明确指定功率 NPZ；未指定 `--data` 时自动配套读取 cube 同目录文件 |
| `--scene`、`--inside`、`--metadata` | 明确指定对应配套文件 |
| `--config` | JSON 配置文件；默认 `configs/default.json` |
| `--out` | 输出目录；默认 `outputs/synthetic` |
| `--validate-only` | 只校验输入与参数，不创建输出 |
| `--preview-only` | 只输出预览图和运行记录 |
| `--preview`、`--no-preview` | 导出视频时开启或关闭预览 |
| `--overwrite` | 允许替换已有生成结果；不会删除其他文件 |

## 扫描与编码

| JSON 字段 | 默认值 | 作用 |
|---|---|---|
| `axes` | `["z","x","y"]` | 选择与排列扫描方向，命令行如 `--axes z x` |
| `quantities` | `["coherent","incoherent"]` | 选择功率种类 |
| `fps_x`、`fps_y`、`fps_z` | 20、20、6 | 每秒帧数，正整数 |
| `frames_x`、`frames_y`、`frames_z` | 240、300、`null` | 均匀抽样帧数；`null` 表示该方向所有切片 |
| `width`、`height` | 1920、1440 | 输出像素尺寸，至少 320×240，须为 16 的倍数 |
| `preview` | `true` | 同时输出预览图 |

抽样包括首尾切片，只有一帧时取第一片，帧数大于体素数时取全部切片；不会复制帧。视频时长约等于实际帧数除以帧率。想放慢扫描可以降低 fps；想让扫描细致可以增加数据层数或抽样帧数。

例如 Manhattan 小样例的 z 方向只有 9 层，以 6 fps 播放约为 1.5 秒。快速配置最多取每个方向 8 帧、8 fps，因此视频约为 1 秒；合成样例 z 只有 6 层，约为 0.75 秒。

## 相机与外观

| JSON 字段 | 默认值 | 作用 |
|---|---|---|
| `elevation` | 28 | 相机俯仰角，度 |
| `azimuth` | -60 | 相机水平角，度 |
| `z_scale` | 1.0 | 显示时的 z 方向比例；原数据不变 |
| `zoom` | 1.0 | 完整场景贴合后的放大倍率；增大可能裁边 |
| `building_opacity` | 0.35 | 建筑透明度，0 到 1 |
| `slice_opacity` | 1.0 | 功率切片透明度，0 到 1 |
| `tx_radius` | 4.5 | 发射点标记半径，米 |
| `ground_z` | 0.0 | 地面高度，米 |
| `cmap` | `turbo` | PyVista 支持的颜色映射名称 |

建筑颜色、地面颜色和发射点红色固定在 `src/video_export/renderer.py` 的 `make_plotter` 中。常规使用可通过配置和命令行调整表内参数，无需修改代码。

## 功率色条

| JSON 字段 | 默认值 | 作用 |
|---|---|---|
| `display` | `native` | 保留输入单位；`path_gain` 将接收功率转换为路径增益 |
| `dyn_range` | 70 | 动态范围，dB |
| `vmax` | `null` | 色条上限；默认取当前功率种类的有限最大值 |
| `vmin` | `null` | 色条下限；默认 `vmax - dyn_range` |

色条范围按每种功率分别确定，同一种功率的各方向保持相同范围。要对照不同数据或相干与非相干画面，显式设置统一的 `vmin` 和 `vmax`。显示单位转换后，`vmin`、`vmax` 应使用转换后的单位。

`NaN` 未覆盖点显示为最低颜色；建筑内部掩码点显示为透明。色条范围外的有限值采用端点颜色。全为 `NaN` 的输入会报错。

## 输出与运行记录

视频名为 `sweep3d_<方向>_<功率种类>.mp4`；预览名为 `preview3d_<方向>_<功率种类>.png`。预览 x/y 尽量取最接近发射点的切片，z 取中间层；没有发射点时都取中间层。

`run.json` 保存实际配置、输入 SHA256、数据元信息、依赖版本、实际帧索引、色条范围和完成状态。失败时尽可能保存失败原因。复制目录后，旧参考运行记录中的路径仍表示生成时的位置；新运行会记录新位置。
